==================================================
  วิธีใช้โฟลเดอร์ data/
==================================================

โฟลเดอร์นี้ใช้วางไฟล์ Navisworks ที่ต้องการถอดข้อมูล

--------------------------------------------------
ขั้นตอน
--------------------------------------------------

1. วางไฟล์โมเดล (.nwd / .nwf / .nwc) ไว้ในโฟลเดอร์นี้
   ตัวอย่าง:
     data\CASE2_AR.nwc
     data\PROJECT_STRUCTURE.nwd

2. รัน run_export.ps1 เพื่อถอดข้อมูลเป็น JSON
   เปิด PowerShell แล้วพิมพ์:
     .\run_export.ps1

   ถ้ามีหลายไฟล์ในโฟลเดอร์ สคริปต์จะถามว่าต้องการไฟล์ไหน

3. ผลลัพธ์ JSON จะถูกบันทึกไว้ที่:
     data\export\<ชื่อไฟล์>.json

4. รัน start.ps1 เพื่อเปิด Web Dashboard
     .\start.ps1

5. เปิด Browser ไปที่:
     http://127.0.0.1:8000
   แล้วกด Refresh from MCP

--------------------------------------------------
โฟลเดอร์ย่อย
--------------------------------------------------

  data\          <- วางไฟล์ .nwd / .nwf / .nwc ที่นี่
  data\export\   <- JSON ที่ถอดออกมาจะอยู่ที่นี่ (สร้างอัตโนมัติ)

--------------------------------------------------
หมายเหตุ
--------------------------------------------------

- ไม่ต้องเปิด Navisworks ค้างไว้ระหว่างใช้ Dashboard
- Navisworks จะถูกเปิดแบบ NoGui เฉพาะตอนรัน run_export.ps1
  แล้วปิดเองอัตโนมัติหลังถอดข้อมูลเสร็จ
- ถ้าอัปเดตโมเดล ให้รัน run_export.ps1 ใหม่อีกครั้ง
  แล้วกด Refresh from MCP บน Dashboard ได้เลย
